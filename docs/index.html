How it works

Loka is one program with nothing else to install. Run it and it opens in your browser.

Run Loka on both computers

Each one finds the other on the network by itself. You don't need an account.

Pick files and a device

Choose files or a directory, or drop them on the page. Then select the device to send to.

Accept on the other side

The receiver chooses where to put the files. The first time, both show a pairing code. Check it's the same on both.

Features

Encrypted

Loka encrypts transfers between two computers running it. Each remembers the other after the first transfer and refuses a device that only poses as it.

Phones need only a browser

Scan the QR code from Receive from a phone and send files from the phone's browser. The computer asks before it saves anything.

Download links

For someone without Loka, create a link with a QR code. It works in any browser while you share. Directories download as a ZIP.

Finds devices by itself

Computers running Loka on the same network show up on their own. If one doesn't, enter its address.

Files and whole directories

Send files of any size and whole directories. Several transfers can run at once, and each shows its speed.

Loka never overwrites files

Incoming files move into place only when the transfer finishes. A failed transfer leaves nothing behind.

Browser or terminal

Use the page in your browser, or send, receive and share from the terminal. Both are the same program.

Nothing leaves your network

Files go straight between your devices. Loka has no account and no server, and sends nothing outside your network.

Light or dark, English or Ukrainian

The page follows your system's light or dark setting and your browser's language. Buttons in the header switch both.

In the terminal too

The same program works without a browser, over SSH or in scripts.

  • loka devices lists nearby devices and marks the ones Loka remembers.
  • loka send sends files and directories to an address.
  • loka receive asks where to put each transfer.
  • loka share prints a link and its QR code, and a curl command that stops if another device answers.

Questions

Is it free?

Loka is free. The MIT-licensed code is on GitHub.

How do I install it?

Download the archive for your computer from Releases, unpack it, and put loka (loka.exe on Windows) in a directory on your PATH. Then run loka.

macOS refuses to open downloaded programs from unidentified developers. After unpacking, run this once. 

xattr -d com.apple.quarantine loka

With Go installed, you can instead run go install github.com/sprytnyk/loka@latest.

How do I check a download?

Put SHA256SUMS and SHA256SUMS.asc from the release next to the archive and run this. 

gpg --verify SHA256SUMS.asc SHA256SUMS && sha256sum --ignore-missing -c SHA256SUMS
How do I send from a phone?

On the computer, select Receive from a phone and scan the QR code with the phone's camera. Choose files or a directory and send. The computer asks you to accept, as with any transfer. iPhones and iPads can send files but not directories, because their browsers can't choose a directory.

A computer on several networks shows a QR code for each. Use the one on the same network as the phone.

Why does the phone ask to install a certificate?

So the phone's browser can check that it reached your computer and not another device. Install it once, and from then on the page opens over HTTPS without a warning. You can also skip it. Loka still encrypts the connection, but the browser warns that it can't check which device answered.

The certificate can only vouch for addresses on local networks, so it can't be used to pose as a web site. Loka never installs it on the computer itself. The README shows how to check its fingerprint before you trust it.

What is the pairing code for?

The first time two devices talk, both show a six-digit code. If they match, no other device is passing the transfer on. If one is, the codes differ. After that first transfer, Loka remembers the other device and refuses one that only poses as it.

The computers can't see each other. What now?

Some Wi-Fi networks block connections between devices, often guest networks. Try another network, or enter the other computer's address and port by hand. On Windows, allow Loka through the firewall when asked. If the port is busy, run loka --port 0 to use a free one.

Where do received files go?

To the directory you choose when you accept. Files arrive in a hidden directory inside it and move into place when the transfer finishes. Loka never overwrites a file, and a failed transfer leaves nothing behind. Loka remembers the last destination until it stops.

Does it send anything outside my network?

No. Loka has no account, no server and no tracking. Files go straight from one device to the other. The page on your own computer opens at http://127.0.0.1, which never leaves it. PROTOCOL.md describes how devices talk, step by step.
