How it works

Run Loka on both computers

Loka finds the other computer on your local network.

Pick files and a device

Choose files or a directory, or drop them on the page. Then select the device you want to send them to.

Accept the transfer

Choose where to save the files on the receiving computer. The first time, check that both computers show the same pairing code before you accept.

On a phone, open a link from Loka or scan its QR code.

Features

Encrypted transfers

When both computers run Loka, each remembers the other's certificate after the first transfer. Loka refuses a transfer if that certificate changes. On a phone, install Loka's certificate to let the browser verify your computer.

Send from a phone

Select Receive from a phone and scan the QR code to send files from the phone's browser. The computer asks you to accept the files.

Download links

Create a link or share its QR code. The recipient can download the files in a browser while you're sharing. Directories download as a ZIP.

Find devices on the same network

Loka lists other computers running Loka on your network. If a computer is missing from the list, enter its address.

Files and directories

Send files of any size or a whole directory. Run several transfers at once and see the speed of each.

Keep existing files

If report.pdf already exists, Loka saves the incoming file under a name like report (1).pdf.

Browser or terminal

The same executable opens the browser page and runs the terminal commands for sending, receiving and sharing files.

Works without internet access

Devices send files directly over your local network. Loka works even if your internet connection drops.

Theme and language

Loka uses your system theme and browser language. Switch between light and dark or English and Ukrainian in the header.

Terminal commands

  • loka devices lists devices running Loka on the same network and marks the ones it remembers.
  • loka send sends files and directories to an address. Pipe in text with --stdin.
  • loka receive asks where to save files and prints incoming text. On your phone, scan the QR code from the terminal and choose Text.
  • loka share prints a link and its QR code. It also prints a curl command that stops if another device answers.

Questions

Is it free?

Loka is free. You can find the code and its MIT licence on GitHub.

How do I run Loka?

Download the archive for your computer from Releases and unpack it. On Windows, double-click loka.exe. On Linux or macOS, run ./loka from the unpacked directory. To run Loka from any directory in the terminal, put the executable on your PATH.

If macOS blocks Loka because it doesn't recognise the developer, run this once from the unpacked directory. 

xattr -d com.apple.quarantine loka

If you have Go installed, you can also run go install github.com/sprytnyk/loka@latest.

How do I check a download?

Put SHA256SUMS and SHA256SUMS.asc from the release alongside the archive. Run this command to check the download. 

gpg --verify SHA256SUMS.asc SHA256SUMS && sha256sum --ignore-missing -c SHA256SUMS
How do I send from a phone?

On the computer, select Receive from a phone. Scan the QR code with the phone's camera. Choose files or a directory and send them. The computer asks you to accept. On iPhone and iPad, choose files because their browsers can't select directories.

A computer on several networks shows a QR code for each. Use the one on the same network as the phone.

Why does the phone ask to install a certificate?

The certificate lets your phone's browser check which computer answered. Install it once to open Loka over HTTPS without a warning. If you skip it, Loka still encrypts the connection and the browser warns that it can't verify which device answered.

The certificate only covers local network addresses, so someone can't use it to pose as a website. Loka leaves the computer's trusted certificates alone. The README shows how to check the certificate's fingerprint before you trust it.

What is the pairing code for?

Two computers running Loka show a six-digit code the first time they connect. Compare the codes before accepting. A mismatch means another device could be forwarding the connection. After the first transfer, each Loka remembers the other's certificate and refuses a transfer if it changes. On a phone, the browser verifies your computer using the certificate you install.

The computers can't see each other. What now?

Some Wi-Fi networks, especially guest networks, block connections between devices. Try another network, or enter the other computer's address and port by hand. On Windows, allow Loka through the firewall when asked. If the default port is busy, try loka --port 45000.

Where do received files go?

Loka saves files in the directory you choose when you accept. Incoming files stay in a hidden directory until the transfer finishes. If a name is already in use, Loka adds a number to the incoming file's name. If the transfer fails, Loka removes the temporary files. It remembers the last directory until you quit.

Does it send anything outside my network?

Files go directly between devices on your network. Loka doesn't track you. It opens its page at http://127.0.0.1, an address that only works on your computer. PROTOCOL.md describes how devices connect and transfer files.
